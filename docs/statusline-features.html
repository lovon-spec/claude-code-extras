user@host
User + short hostname.Helpful when SSHing between machines or running multiple sandboxes — at-a-glance "which box am I on".
/path/to/cwd
Current working directory.For worktrees, the path itself is the cleanest "which worktree" identifier.
●N
N modified, staged, or untracked files.Hidden when the worktree is clean. Reminds you that there's uncommitted work before you switch tasks or close a session.
[Model]
Active Claude model.Distinguishes Opus / Sonnet / Haiku at a glance — useful when juggling sessions on different models.
██████░░░░ 63%
Context-window usage as a 10-cell bar + percentage.Tells you when to wind down a session before the context fills (compaction kicks in around the high end).
+N/-M
Commits ahead / behind origin/<primary> (falls back to local if no origin).Compares against the remote tip rather than your possibly-stale local main, so a fresh worktree off origin/main reads +0/-0 correctly.
✓ / ⚠
Merge-parity preview vs the primary branch.✓ = merging would be clean (fast-forward in either direction OR a 3-way merge that git merge-tree says succeeds). ⚠ = it would conflict. Cached by HEAD-sha + main-sha.
⇡N
Current branch has N commits past its upstream (what git push would send). Hidden if no upstream is set.Reminds you to push before quitting. Visible ⇡0 means "I checked, you're synced."
main⇡M
Primary branch has M unpushed commits, shown only when current ≠ primary.For solo-dev workflows that merge into main and push from there: tells you "you have local-only merges on main from elsewhere".
YYYY-MM-DD HH:MM:SS
Local time.Quick reference inside the TUI without leaving for a clock.
abcd1234
First 8 chars of this session's UUID.Distinguishes tabs visually; also useful as a copy-paste ID for claudet -s <prefix> if auto-detection ever needs an override.
⏳54:07
Prompt-cache time-to-live; desktop notification before expiry (locally, or via OSC escapes over ssh).Auto-detects the 1 h (subscription) vs 5 min (API) cache from the transcript. Green → yellow → red as expiry nears; dim ⏳✗ once cold — the next message then re-writes the full context.
All git probes are fetch-free; merge-tree is gated on git ≥ 2.38 and skipped silently otherwise. ●N uses --no-optional-locks to avoid index-lock contention with concurrent agent activity.
